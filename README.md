## Cómo Usar Este Curso

    {{1}}
**Navegación:** Usa los botones `<` y `>` en la parte superior para avanzar por las secciones, o haz clic en el menú lateral para saltar a un módulo específico.

    {{2}}
**Modos de visualización:** En la esquina superior derecha puedes cambiar entre tres modos:

- **Libro:** Texto continuo, ideal para lectura profunda
- **Presentación:** Con animaciones y text-to-speech en español
- **Slides:** Como una presentación de diapositivas

    {{3}}
**Quizzes interactivos:** Cada módulo contiene quizzes que puedes responder directamente. Haz clic en "Check" para verificar tu respuesta y "Resolve" para ver la explicación. Los hints `[[?]]` te ayudan si te atascas.

**Ejercicios prácticos:** Los módulos incluyen ejercicios paso a paso que debes ejecutar en tu propia terminal. El aprendizaje ocurre con la práctica, no con la lectura.

    {{5}}
**Progreso:** LiaScript guarda tu progreso automáticamente en el navegador. Puedes cerrar y volver cuando quieras — encontrarás el curso donde lo dejaste.

## Información del Curso

### Objetivos de Aprendizaje

Al completar este curso serás capaz de:

- [X] Instalar, configurar y manejar Claude Code con fluidez profesional
- [X] Diseñar sistemas de memoria multi-capa con CLAUDE.md y Auto Memory
- [X] Extender Claude Code con skills, hooks, slash commands y servidores MCP
- [X] Crear y orquestar equipos de agentes especializados para todo el ciclo de desarrollo
- [X] Implementar pipelines de CI/CD integrados con Claude Code en modo headless
- [X] Reducir el coste operativo hasta un 80% mediante selección inteligente de modelos
- [X] Aplicar defense in depth con 4 capas de seguridad automatizadas
- [X] Dominar patrones avanzados: Coordinator Mode, BVI Chains, Debate Pattern

### Audiencia

Este curso está diseñado para:

- **Desarrolladores** que quieren maximizar su productividad con IA
- **Tech Leads y Engineering Managers** que buscan estandarizar workflows de equipo
- **Product Owners técnicos** interesados en integrar IA en el ciclo de desarrollo
- **Arquitectos de software** diseñando sistemas con agentes IA
- **DevOps y SRE** automatizando pipelines con Claude Code

### Prerrequisitos

- Conocimientos básicos de terminal y línea de comandos
- Familiaridad con Git y control de versiones
- Experiencia general en desarrollo de software (cualquier lenguaje)
- Cuenta de Anthropic con acceso a Claude Code (plan Pro, Max o Enterprise)
- Node.js 18+ instalado (para la instalación de Claude Code)

### Tiempo Estimado

| Nivel | Tiempo acumulado |
|:------|:----------------:|
| Principiante (Módulos 1-2) | ~2 horas |
| Intermedio (Módulos 1-4) | ~5 horas |
| Avanzado (Módulos 1-6) | ~8 horas |
| Experto (Módulos 1-8) | ~12 horas |

> **Recomendación:** No intentes completar el curso de una vez. Distribúyelo a lo largo de 2-4 semanas, aplicando cada módulo en un proyecto real antes de pasar al siguiente.

## Índice de Módulos

### Nivel Principiante

**Módulo 1: Fundamentos y Setup Inicial** _(45-60 min)_

Instalación, configuración y primera sesión con Claude Code. Entenderás qué es Claude Code, cómo se diferencia de un chatbot convencional, los modelos disponibles y el sistema de permisos.

- 1.1 ¿Qué es Claude Code?
- 1.2 Superficies de Acceso (CLI, Desktop, VS Code, JetBrains)
- 1.3 Modelos Disponibles (Opus, Sonnet, Haiku)
- 1.4 Instalación Paso a Paso
- 1.5 El Sistema de Permisos
- 1.6 Anatomía de una Sesión
- 1.7 Ejercicio: Tu Primera Sesión Completa

    {{1}}
**Módulo 2: Memoria y Gestión de Contexto** _(60-75 min)_

La diferencia entre usuario casual y profesional se mide en cómo gestionas el contexto. Este módulo te enseña a construir la memoria que convierte a Claude Code en un compañero que recuerda.

- 2.1 Las Tres Capas de Memoria
- 2.2 CLAUDE.md — La Constitución del Proyecto
- 2.3 Auto Memory — Claude Aprende de Ti
- 2.4 Reglas Modulares con `.claude/rules/`
- 2.5 Gestión de la Ventana de Contexto
- 2.6 La Rutina de Sesión Óptima
- 2.7 Antipatrones: Lo Que NO Hacer
- 2.8 Ejercicio: Construye tu CLAUDE.md

### Nivel Intermedio

    {{2}}
**Módulo 3: Extensibilidad — Skills, Slash Commands, Hooks y MCP** _(75-90 min)_

Claude Code no es solo un asistente. Es una plataforma extensible. Aprenderás los cuatro mecanismos de extensión y cuándo usar cada uno.

- 3.1 Mapa de Extensiones
- 3.2 Slash Commands — Atajos Manuales
- 3.3 Skills — Automatización Inteligente
- 3.4 Hooks — Automatización Reactiva
- 3.5 MCP — Model Context Protocol
- 3.6 Plugins — Empaquetado y Distribución
- 3.7 Cómo Se Combinan en la Práctica
- 3.8 Tabla de Decisión Rápida

    {{3}}
**Módulo 4: Agentes Especializados** _(90-120 min)_

El corazón del curso. Diseñarás e implementarás un roster de 7 agentes especializados que cubren desde la especificación de features hasta la revisión de seguridad.

- 4.1 Los Tres Niveles de Delegación
- 4.2 Subagentes — Delegación Ad-Hoc
- 4.3 Custom Agents — Tu Equipo de Especialistas
- 4.4 Diseño del Roster Completo (7 agentes)
- 4.5 Agent Teams — Colaboración Multi-Agente
- 4.6 Coordinator Mode y Builder-Validator Pattern
- 4.7 Ejercicio: Monta tu Roster

### Nivel Avanzado

    {{4}}
**Módulo 5: Workflows Profesionales** _(75-90 min)_

Conecta todo en pipelines ejecutables de principio a fin: Feature Lifecycle completo, Git workflows, CI/CD integrado y monitorización continua.

- 5.1 El Workflow Feature Lifecycle (7 fases)
- 5.2 Git Workflows con Claude Code
- 5.3 Modo Headless y CI/CD
- 5.4 Loop Continuo
- 5.5 Workflow Completo: De Idea a Deploy
- 5.6 Patrones de Workflow Avanzados

    {{5}}
**Módulo 6: Optimización de Tokens** _(60-75 min)_

Los tokens son el combustible de Claude Code. Un contexto optimizado produce mejores respuestas y reduce costes hasta un 80%.

- 6.1 Por Qué Importa la Optimización
- 6.2 Anatomía del Consumo de Tokens
- 6.3 Siete Estrategias de Reducción
- 6.4 Selección de Modelo por Rol de Agente
- 6.5 Morph MCP: Ediciones y Búsquedas Optimizadas
- 6.6 Monitorización y Control de Costes
- 6.7 Checklist de Optimización
- 6.8 Ejercicio: Auditoría de Consumo

### Nivel Experto

    {{6}}
**Módulo 7: Seguridad y QA Integrados** _(75-90 min)_

La seguridad no es un paso al final del pipeline. Es una propiedad que se integra en cada capa. Aprenderás defense in depth con 4 capas automatizadas.

- 7.1 Defensa en Profundidad: El Modelo de Capas
- 7.2 Capa 1: Prevención
- 7.3 Capa 2: Runtime Checks con Hooks
- 7.4 Capa 3: Análisis Reactivo con Agentes
- 7.5 El Agente de QA Avanzado
- 7.6 Capa 4: CI/CD con Quality Gates Bloqueantes
- 7.7 Workflow Completo de Seguridad
- 7.8 Gestión de Vulnerabilidades Continua

    {{7}}
**Módulo 8: Patrones Avanzados** _(90-120 min)_

El módulo de cierre. Patrones que solo tienen sentido después de dominar todo lo anterior: Coordinator Mode, BVI Chains, Debate Pattern y métricas del pipeline.

- 8.1 Coordinator Mode en Profundidad
- 8.2 Builder-Validator Chains Avanzados
- 8.3 Debate Pattern para Decisiones Arquitectónicas
- 8.4 Extended Thinking y Effort Level

- 8.7 El Camino al Siguiente Nivel
- 8.8 Cierre del Curso

- [( )] Un chatbot web para hacer preguntas sobre código
